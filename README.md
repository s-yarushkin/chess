# Шахматная академия / Chess Academy

**v0.5: готовим закрытый пилот с приглашёнными взрослыми; детский публичный запуск пока закрыт.**

## Что уже есть

- Мат в 1, 2 и 3 хода, подсказки и игровые анимации, уровни и достижения.
- 3 000 Lichess CC0 задач из реальных партий: 900/1 100/1 000, со ссылками на источник, учебными темами и рейтингом.
- Школьный путь для 8–9 лет: постепенное усложнение, 5 задач на короткую миссию, без штрафа за перерыв.
- Прогресс и баллы считаются на сервере и сохраняются в SQLite WAL.
- Социальные функции в исходном коде, но **выключены при первом запуске** до полноценного родительского управления.

## Разработка

Node.js 22.5+ (рекомендуется 22 LTS), сторонние npm-пакеты не требуются.

```bash
npm test
npm run catalog:check
npm run catalog:import
npm run dev
```

Доступ в локальном режиме: http://127.0.0.1:8094 . В режиме production тестовый вход по имени отключён.

## Закрытый серверный пилот

См. **[docs/PILOT-DEPLOY.md](docs/PILOT-DEPLOY.md)** — команды установки Ubuntu Docker, DNS, HTTPS через Caddy, настройки .env, импорта 3 000 задач, включения Telegram-бота и резервирования.

После выделения отдельной Ubuntu VM, настройки домена, создания бота и получения цифровых Telegram ID взрослых тестировщиков:

```bash
bash scripts/bootstrap-ubuntu.sh  # под root на новой VM
bash scripts/init-env.sh
nano .env
bash scripts/launch-pilot.sh
```

- Порт Node.js и SQLite не открывается в Интернет; снаружи только HTTPS.
- .env и резервные копии исключены из Git и Docker-образа.
- Сервер проверяет Telegram initData и список взрослых ID даже для ранее выданных сессий.
- Конфигурация с DEV_MODE=1 и FRIENDS_ENABLED=1 отклоняется.
- Docker healthcheck, внешний /readyz, Telegram getMe + webhook verification.
- Ежедневные согласованные резервные копии SQLite через Online Backup API, локально 14 дней. Нужна отдельная внешняя копия.
- На данный момент нет семейных аккаунтов, юридического согласия родителей, полноценного школьного UX-теста и подтверждённой работы на реальном HTTPS-хосте.
