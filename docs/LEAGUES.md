# Шахматные лиги · первая версия

Лиги — закрытые группы для знакомых игроков. **Не являются публичными турнирами** с партиями по расписанию.

## Как игроки попадают в лигу
1. В профиле включают «Делиться прогрессом с подтверждёнными друзьями и участниками моих лиг».
2. Создатель выбирает вкладку «Лиги» → «Создать» и вводит короткое название.
3. Создатель получает код, который действует семь дней, и передаёт его знакомым.
4. Друг вводит код и нажимает «Подать заявку». Автоматического вступления нет.
5. Создатель видит никнейм кандидата и отдельно принимает или отклоняет заявку.
6. Участники видят только никнеймы и результаты по первым восьми новым задачам за текущие семь дней.

## Ограничения и безопасность
- До 20 участников и не более трёх лиг для одного аккаунта; создатель может создать максимум две.
- Нет глобального каталога лиг, поиска незнакомых игроков, чатов, контактов и отметок присутствия.
- При выключении обмена прогрессом результаты немедленно скрываются из чужих списков.
- Создатель может удалить участника, а игрок может выйти самостоятельно.
- Коды приглашений хранятся как SHA-256-хеши; создаётся не более четырёх кодов за сутки на лигу, лимит 20 использований кода.
- Недельный рейтинг считает только первые восемь уникально решённых задач, исключая бесконечную гонку по количеству времени.
- Индивидуальная дружба по одноразовым кодам остаётся отдельным режимом.
- Полноценные турниры (сеточные пары, партии, сроки, награды) требуют отдельного этапа и механизмов справедливого судейства.

## Проверки
- `npm test` — включает PostgreSQL-сценарий создания лиги, подачи заявки, запрета доступа постороннего, одобрения создателем, подсчёта недельных очков и скрытия прогресса.
- GitHub Actions поднимает отдельную временную PostgreSQL 16 без доступа к production Neon.
- После релиза требуются ручные сценарии в Telegram с двумя аккаунтами и повторным входом.
