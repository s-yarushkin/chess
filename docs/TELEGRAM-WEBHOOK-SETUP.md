# Подключение личных уведомлений Telegram

У шахматного бота используется Telegram webhook:

`https://chess-academy-theta.vercel.app/telegram/webhook`

## Почему молчат /start и /registrations

Mini App получает доступ к Telegram независимо от webhook. Чтобы Telegram доставлял в Vercel текстовые сообщения, один раз нужно вызвать `setWebhook`. Также сервер проверяет секретный заголовок `X-Telegram-Bot-Api-Secret-Token`. Без настроенного webhook входящие команды не доходят до обработчика.

## Без передачи токена в чат и без командной строки

1. В Vercel Production должны быть `TG_BOT_TOKEN`, `REGISTRATION_ADMIN_CHAT_ID` и `REGISTRATION_ADMIN_USERNAME`. Две последние переменные предназначены строго для личного Telegram-аккаунта получателя. После их изменения требуется Redeploy.
2. Открой Chess Academy из личного аккаунта администратора через сам Telegram-бот.
3. В профиле появится **«Служебные уведомления» → «Подключить сообщения от бота»**. Блок создаётся только после проверки подписи Telegram и правильности настроенного администратора на сервере. Обычным пользователям он не отображается.
4. Нажатие выполняет `getChat`, `setWebhook`, `getWebhookInfo` с защищённым webhook. Секрет берётся из `TG_WEBHOOK_SECRET`, если он задан, либо детерминированно выводится через HMAC-SHA256 из существующего `TG_BOT_TOKEN`. Не публикуй эти секреты.
5. После сообщения «Telegram подключён» отправь боту в личном чате `/registrations`. Затем зарегистрируй нового тестового пользователя и проверь личное уведомление.

Если блок не появляется у администратора, проверь значения регистрационных переменных и Production Redeploy. Сервер умышленно не раскрывает их посторонним.

## Защита

- Только подписанный Telegram initData администратора, соответствующий ранее созданному пользователю/связанному Telegram-алиасу, может активировать webhook.
- Сервер дополнительно сверяет тип чата, Telegram ID и username через Bot API `getChat`.
- URL webhook фиксирован на production-адресе проекта, не берётся из тела запроса.
- Включается только получение сообщений (`allowed_updates=['message']`); входящие запросы без секретного заголовка получают 403.
- Команда `/registrations` отвечает только в личный чат подтверждённого администратора.
- Уведомления не содержат никнеймов, Telegram ID и иных персональных данных игроков.

Проверка конфигурации Telegram: официальный Bot API `getWebhookInfo` — https://core.telegram.org/bots/api#getwebhookinfo.
