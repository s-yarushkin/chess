# Напоминания о шахматных задачах

- У новых игроков включены по умолчанию, без отдельного согласия. Профиль показывает состояние и позволяет выключить. Одноразовая миграция включает старые профили, которые не открывали приложение после введения настройки и не получали напоминаний. Настройки уже посещавших новую версию сохраняются, поскольку прежняя схема не различала явное отключение и значение по умолчанию. Для старых профилей без отметки активности используется последняя игровая активность или сессия.
- После более 7 дней без входа/запросов игры, не чаще одного раза за неделю, максимум два сообщения за перерыв. Возврат к игре сбрасывает счётчик, не сбрасывая индекс заметки.
- 36 уникальных коротких советов по шахматам в `src/practice-reminders.js`; порядок циклический. Нет заявлений о здоровье и давящих текстов.
- `/stop` или выключение переключателя отменяет дальнейшие сообщения. Отказ Telegram (403) отключает напоминания.
- Vercel Cron ежедневно в 09:00 UTC (12:00 МСК; возможна задержка на Hobby). Дополнительный серверный контроль дневного времени. В production требуется переменная `CRON_SECRET` длиной не менее 24 символов. Без неё endpoint закрыт и сообщения не отправляются.
- Доставка защищена атомарным резервированием; при неопределённой ошибке нет немедленного повтора. Служебные данные и секреты не выводятся в ответы.
