# Продуктовая дорожная карта

## Этап 0 — технический прототип (есть в этом репозитории)

Сервер, хранение, подтверждение Telegram-входа, профиль с ником, проверка ходов, начисление баллов (1/2/3/3), первый личный и общий рейтинг, адаптивный подбор, импортёр Lichess, Mini App, автоматические тесты. Готов к локальному запуску, **не к публичной эксплуатации**.

## Этап 1 — качественный школьный каталог

- Минимум 300 `mate1`, 500 `mate2`, 300 `mate3`. Плановый первый импорт — по 750 позиций каждой матовой категории, отбирать по популярности, рейтингу и проверке корректности.
- Группы сложности 600–1000, 1000–1400, 1400–1800, 1800+; индивидуальная настройка по ошибкам и времени решения.
- Не менее 200 **настоящих** задач на ничью: форсированный пат, вечный шах, точная защита в пешечном/ладейном эндшпиле, теоретическая ничья. Нужна экспертиза (Stockfish + tablebase Syzygy для позиций с малым числом фигур). Никакой имитации ничьих через последний взятый пешечный материал.
- Каждая задача: источник, FEN, эталонные ходы, уровень, тип тактики, заключение валидатора, идентификатор источника.
- Отбраковка дубликатов по FEN, ручная ревизия случайной выборки и трудных случаев.

## Этап 2 — серверный production

Отдельный GitHub-репозиторий (для закрытого кода — Private), PostgreSQL 16, новая БД, контейнер или systemd, Caddy TLS, резервирование, секреты, журнал действий, CI/CD на собственный тестовый сервер, мониторинг ошибок. Заранее определить домен и нового бота. Не затрагивать проекты с банями, финансовые сервисы и существующие боты.

## Этап 3 — Telegram Mini App с игровым опытом (v0.2 — частично готово)

В v0.2 реализованы игровые эффекты, отключаемые звуки, 11 наград, прогресс уровней, серверные серии чистых решений и корректные линии атаки. Ещё не сделаны проверка на реальных устройствах Telegram, восстановление незаконченной задачи между сеансами и расширенный учебный режим. Никакой обязательной прокрутки вниз.

## Этап 4 — педагогика, соревнования и развитие

- Временные подборки на 10–15 минут, повтор ошибочных через 1/3/7 дней, статистика по мотивам (связки, двойной удар, открытое нападение, мат по последней горизонтали).
- Недельные лиги и отдельные рейтинги уровня новичков, без публикации персональных данных.
- Уровни новичок → ученик → тактик → мастер, без бесконечного повторения одних и тех же позиций.
- Режим «учитель»: подбор домашнего задания, анализ ошибок и отчёты без избыточного сбора данных детей.
- Движковая проверка всех защит в мате 2/3, принятие любых равноценных решений.
- Возможность отдельного web/PWA клиента с дополнительным способом входа, не ломая Telegram-учётки.

## Критерий релиза

Должны пройти CI, безопасность Telegram, тесты двух аккаунтов, отсутствие повторного начисления баллов, минимум задач по каталогу, настоящие ничейные позиции, проверенные бэкапы и реальное тестирование мобильного интерфейса.
