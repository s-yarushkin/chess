# Развёртывание Chess Academy v0.5: закрытый пилот

**Сейчас ничего на существующих серверах не меняем.** Сценарий ниже рассчитан на отдельную Ubuntu VM. Публичный детский вход пока не реализован; в пилот входят только приглашённые взрослые, у которых есть разрешённый Telegram-аккаунт.

## Требуется для следующего шага

Новая Ubuntu 24.04/22.04 VM с публичным IP, ориентир 2 CPU, 2–4 ГБ RAM и SSD от 20 ГБ. Нужны DNS A-запись поддомена на IP VM и свободные порты TCP 80/443 (UDP 443 опционально). Не ставить рядом с существующими Caddy/Nginx, уже использующими 80/443. Нужны токен нового бота из BotFather и **числовые Telegram ID 1–30 приглашённых взрослых**, а не их имена или номера телефонов. Не сообщать токен в GitHub или чат.

## Запуск (на новой VM от root)

```bash
apt-get update && apt-get install -y git
git clone https://github.com/s-yarushkin/chess.git /opt/chess
cd /opt/chess
bash scripts/bootstrap-ubuntu.sh
bash scripts/init-env.sh
nano .env
# В .env: APP_DOMAIN, WEBAPP_URL=https://APP_DOMAIN,
# TG_BOT_TOKEN, PILOT_TELEGRAM_IDS
bash scripts/launch-pilot.sh
```

При необходимости IDN-домен указывается как punycode. `init-env.sh` создаёт `.env` с правами 600 и отдельным случайным Telegram webhook secret. Не менять `NODE_ENV=production`, `DEV_MODE=0`, `FRIENDS_ENABLED=0`.

Сценарий **проверяет секреты без их вывода**, поднимает Docker + Caddy, импортирует 3 000 задач (900/1100/1000), проверяет `https://DOMAIN/readyz`, затем вызывает Telegram `getMe`, `setWebhook` с проверкой секретного заголовка и `setChatMenuButton`, подтверждает URL через `getWebhookInfo`. После успешного запуска на /opt/chess от root включает ежедневный systemd-таймер backup.

## Чек-лист после запуска

1. `docker compose ps` — два контейнера, приложение healthy; `curl -fsS https://DOMAIN/readyz` — `ready:true`, категории 900/1100/1000 или больше.
2. В личном чате с новым ботом написать `/start`, нажать «Играть», указать никнейм, решить мат и увидеть очки. После перезапуска приложения прогресс должен остаться.
3. Telegram-аккаунт **вне списка** должен получить 403. Локальный вход по имени должен быть недоступен, открытый рейтинг детей пуст, друзья отключены.
4. `bash scripts/backup.sh` — создан `backups/chess-....sqlite`, проверенный SQLite Online Backup API. `systemctl status chess-backup.timer` — enabled.
5. Проверить на смартфоне с реальным Telegram-клиентом; это отдельный непроведённый этап. Не приглашать детей до реализации семейного входа.

## Диагностика и безопасное обновление

```bash
cd /opt/chess
docker compose logs --tail 100 chess
docker compose logs --tail 100 caddy
bash scripts/backup.sh
git rev-parse HEAD
```

При сбое сертификата проверить A-запись, открытость TCP 80/443 и доступность VM извне. При ошибке Telegram проверить `getMe`/webhook через `scripts/setup-bot.js`, не публикуя токены. Резервные копии локально хранятся 14 дней: **обязательно копировать отдельно зашифрованно за пределы VM**. Перед обновлением бэкап, затем переключение на проверенный коммит и повторный `bash scripts/launch-pilot.sh`. Восстановление выполнять **только с остановленным приложением** на отдельной проверенной копии базы; восстановление удалит новые результаты после даты бэкапа.

## Ограничения

Первый пилот — **одно приложение, один SQLite-том**. Node `node:sqlite` может выводить предупреждение об экспериментальном статусе на версии Node 22. Мы не проверили реальные сертификаты, Telegram webhook, телефонные экраны и нагрузку: эти проверки возможны только после выделения VM и данных бота. Для публичного запуска среди детей нужны семейные профили и родительское согласие. Нельзя просто включить детский Telegram-вход или социальный режим.
