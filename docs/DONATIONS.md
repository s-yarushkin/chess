# Добровольная благодарность в Chess Academy

Кнопка «💛 Сказать спасибо» открывает небольшое окно. Все шахматные задачи и достижения остаются бесплатными. Перевод выполняет взрослый в банковском приложении.

## Экран

1. Короткое приветствие и сумма благодарности: 30, 50, 100 ₽ или произвольная от 10 до 10 000 ₽.
2. Главная кнопка **«Открыть Ozon Банк»** с официальной банковской ссылкой.
3. QR-код с той же ссылкой — для сканирования вторым устройством.
4. Короткая инструкция: открыть ссылку/сканировать QR, указать сумму и проверить получателя.

Номер телефона удалён из окна благодарности и из ответа API; реквизиты по номеру не показываются. Перевод не производится сервером Chess Academy, никакие карты и данные об оплате не обрабатываются.

## QR Ozon Банка

По QR, предоставленному владельцем, используется публичная HTTPS-ссылка:
https://finance.ozon.ru/apps/sbp/ozonbankpay/01a204e5-3d38-7ddd-a839-f4cf4724f89f

Ссылка хранится в `DEFAULT_DONATION_OZON_URL` (src/donation.js). Переменная Vercel Production `DONATION_OZON_URL` при наличии переопределяет значение. API генерирует PNG QR, закодировав только разрешённую ссылку Ozon/СБП. Отправитель самостоятельно подтверждает банковский перевод.

**Суммы из интерфейса не передаются в банк автоматически**: официального API динамического формирования платежей мы не подключали. Для банковского перевода нужно вручную указать нужную сумму.

## Выбор банка отправителя
Кнопка называется **«Перевести через СБП»**, а не «Открыть Ozon Банк»: Ozon — банк получателя. Официальный сервис Ozon для чаевых позволяет выбрать банк отправителя (например, Сбер, Т-Банк, ВТБ), указать сумму и подтвердить перевод. Отдельные прямые ссылки каждого банка не нужны. Выбранная сумма в игре — подсказка, динамической передачи суммы в статический QR нет.
