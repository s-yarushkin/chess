# Добровольная благодарность Лёше

В шахматном приложении есть небольшая кнопка «💛 Сказать спасибо». Все шахматные задания, баллы и достижения остаются полностью бесплатными; переводы добровольные. Для школьной аудитории интерфейс прямо указывает, что перевод оформляет взрослый.

## Работает уже сейчас

- Сумма 30 / 50 / 100 ₽ или произвольная от 10 до 10 000 ₽.
- Получатель: **Ozon Банк**; СБП: **+7 921 128-28-45**.
- Можно скопировать номер или все реквизиты вместе с выбранной суммой.
- В банковском приложении отправитель самостоятельно выбирает Ozon Банк и подтверждает получателя, сумму и комиссию.
- Перевод не выполняется через сервер Chess Academy. Приложение не запрашивает карты, не отслеживает переводы и не добавляет преимущества за благодарность.
- Телефон размещён публично в интерфейсе по запросу владельца; при необходимости номер можно заменить в src/donation.js, public/donate.js, public/index.html.

## Как подключить настоящий QR Ozon Банка

В приложении владельца: **Аккаунт → QR для пополнений → Получать чаевые**. Ozon Банк поддерживает QR для чаевых и донатов.

Если банк предоставляет HTTPS-ссылку, встроенную в сгенерированный QR, её нужно добавить в Vercel → Project → Settings → Environment Variables → Production:

DONATION_OZON_URL = https://... (именно ссылка из созданного банковского QR)

После сохранения нужен новый Production Deploy. Сервис сам построит QR-картинку по официальной ссылке. Без банковской ссылки QR не показывается: создание QR из одного телефона не означает настоящий платёж по СБП. Домен ссылки проверяется и может принадлежать только ozon.ru, ozonbank.ru или nspk.ru.

Выбранная в игре сумма НЕ передаётся в банк автоматически, поскольку подтверждённого API для предварительного заполнения суммы у нас пока нет. Донатер указывает сумму в своём банке.
